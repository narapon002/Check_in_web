# เว็บเช็คชื่อพนักงาน — คู่มือติดตั้ง

**เวอร์ชันปัจจุบัน: 1.2.0**

ตรวจสอบเวอร์ชันได้จากข้อความใต้ชื่อเว็บในส่วนหัวของหน้าเว็บ หรือจาก Web app URL ที่แสดงค่า `version`

## ประวัติการเปลี่ยนแปลง

- **1.2.0**
  - ปรับหน้าตาเว็บเป็นธีมพาสเทล ฟอนต์ Mali พร้อมไอคอนบอกสถานะและเมนู
  - ข้อความแจ้งเตือนแสดงเป็นป้ายลอยด้านล่างจอ
- **1.1.0**
  - เพิ่มการอนุมัติของหัวหน้างานด้วยลายเซ็น (ทางเลือก)
  - แสดงจำนวนครั้งที่สายและเวลาสายรวมเป็นตัวอักษรสีแดงในตารางสรุปรายเดือน
  - เพิ่มกราฟแท่งเปรียบเทียบเวลาทำงานตามกำหนดกับเวลาที่มาสายของแต่ละคน
  - ย้ายข้อมูลไปเก็บใน Google Sheet ผ่าน Google Apps Script พร้อมชุดไฟล์สำหรับ GitHub Pages
  - เพิ่มการแสดงเลขเวอร์ชันบนหน้าเว็บ
- **1.0.0** เวอร์ชันแรก ทำงานบนฐานข้อมูลของ claude.ai (ใช้เฉพาะตอนเปิดผ่าน artifact)

ชุดไฟล์นี้ใช้ **Google Sheets เป็นฐานข้อมูล**, **Google Apps Script เป็นหลังบ้าน** และ **index.html เป็นหน้าเว็บ** ใช้ได้ทั้งคอมและมือถือ

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บที่จะนำขึ้นโฮสต์ (ต้องแก้ค่า `API_URL` ก่อน) |
| `Code.gs` | โค้ดหลังบ้าน วางใน Apps Script ของ Google Sheet |
| `employees.csv` | ตัวอย่างฐานข้อมูลพนักงาน 22 คน ใช้นำเข้าได้ |
| `attendance.csv` | โครงสร้างตารางเวลาเข้า-ออกงาน (ยังไม่มีข้อมูล) |
| `README.md` | ไฟล์นี้ |

## ขั้นตอนที่ 1: สร้าง Google Sheet และหลังบ้าน

1. เปิด https://sheets.new สร้าง Google Sheet ใหม่ ตั้งชื่อว่า เช็คชื่อพนักงาน
2. ในเมนู **Extensions > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางเนื้อหาจากไฟล์ `Code.gs` ในชุดนี้
4. กดบันทึก (ไอคอนแผ่นดิสก์)
5. กด **Deploy > New deployment** แล้วเลือก **Web app** ตั้งค่าดังนี้
   - Execute as: **Me**
   - Who has access: **Anyone**
6. กด **Deploy** อนุญาตสิทธิ์ที่ระบบขอ แล้วคัดลอก **Web app URL** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/...`)

> ทุกครั้งที่แก้ `Code.gs` ต้องไปที่ **Deploy > Manage deployments > Edit > New version** ไม่เช่นนั้นการแก้ไขจะยังไม่มีผล

## ขั้นตอนที่ 2: ตั้งค่าหน้าเว็บ

1. เปิดไฟล์ `index.html` ด้วยโปรแกรมแก้ข้อความ (Notepad, VS Code)
2. ค้นหาบรรทัด `const API_URL = ...` แล้วแทนข้อความในเครื่องหมายคำพูดด้วย Web app URL จากขั้นตอนที่ 1
3. บันทึกไฟล์

```js
const API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

## ขั้นตอนที่ 3: นำรายชื่อพนักงานเข้าระบบ

มีสองวิธี เลือกวิธีใดก็ได้

- **วิธีที่ 1 (ผ่านเว็บ):** เปิดหน้าเว็บ ตั้ง PIN หัวหน้างาน แล้วไปที่แท็บ "รายชื่อพนักงาน" อัปโหลด `employees.csv` หรือไฟล์ Excel แล้วกด "บันทึกรายชื่อทั้งหมด"
- **วิธีที่ 2 (ผ่าน Sheet โดยตรง):** เปิดชีต `Employees` ใน Google Sheet แล้วใช้ **File > Import** เลือก `employees.csv` ให้ใส่ข้อมูลลงใน Sheet เดิม และเลือก "Replace current sheet" หรือ "Append" ตามต้องการ โดยต้องมีแถวหัวคอลัมน์ `code, name, dept`

หมายเหตุ: ชีต `Employees`, `Attendance`, `Settings` จะถูกสร้างให้อัตโนมัติตอนมีการเรียกใช้ครั้งแรก

## ขั้นตอนที่ 4: นำหน้าเว็บขึ้นโฮสต์

ไฟล์ `index.html` เป็นไฟล์เดียว ไม่ต้องติดตั้งอะไรเพิ่ม โฮสต์ได้หลายที่ เช่น

- **GitHub Pages:** สร้าง repository แล้วอัปโหลด `index.html` เปิด Settings > Pages
- **Netlify Drop:** ลากโฟลเดอร์ที่มี `index.html` ไปวางที่ https://app.netlify.com/drop
- **เซิร์ฟเวอร์ของบริษัท:** อัปโหลด `index.html` ผ่าน FTP หรือ cPanel ไปยังโฟลเดอร์เว็บ

## การใช้งานครั้งแรก

1. เปิดหน้าเว็บ ระบบจะให้ตั้ง PIN หัวหน้างาน (ตัวเลข 4–8 หลัก) ผู้ที่ตั้งจะเป็นหัวหน้างานคนแรก
2. หัวหน้างานนำรายชื่อพนักงานเข้าระบบ (ขั้นตอนที่ 3)
3. พนักงานเปิดหน้าเว็บ เลือกชื่อตัวเอง แล้วกด "กดเข้างาน" และ "กดออกงาน"
4. หัวหน้างานเปิดแท็บ "ยืนยันการเข้างาน" แล้วกด "ยืนยัน" ทีละคน เลือกเซ็นลายเซ็นหรือไม่ก็ได้
5. ดูสรุปรายเดือน กราฟ และคัดลอก CSV ได้จากแท็บ "สรุปรายเดือน"

## กฎเวลาที่ใช้ในระบบ

- เข้างานตั้งแต่ 08:00 น. เป็นต้นไป นับเป็นสาย และนับนาทีที่เกินจาก 08:00 เป็นเวลาสาย
- ออกงานก่อน 17:00 น. นับเป็น "ออกก่อนเวลา"
- กราฟเปรียบเทียบ: เวลาทำงานตามกำหนด = จำนวนวันที่เข้างาน × 9 ชั่วโมง และเวลาสายรวมแปลงเป็นชั่วโมง

## ข้อจำกัดและข้อควรระวัง

- **ความปลอดภัย:** Web app เปิดให้ "Anyone" เรียกได้ ผู้ที่รู้ URL สามารถอ่านข้อมูลได้ PIN หัวหน้างานเก็บเป็นค่าแฮช SHA-256 และตรวจสอบที่หลังบ้าน แต่ยังไม่ใช่การยืนยันตัวตนแบบเต็มรูปแบบ สำหรับข้อมูลที่เป็นความลับระดับองค์กร ควรเพิ่มระบบ login ของ Google Workspace หรือ Firebase Auth
- **การจำว่าใครเป็นใคร:** เว็บจำสถานะการเข้าสู่ระบบไว้ในเบราว์เซอร์ของแต่ละเครื่อง (localStorage) ถ้าล้างข้อมูลเบราว์เซอร์ต้องเข้าสู่ระบบใหม่
- **ลายเซ็น:** เก็บเป็นข้อความรูปภาพในเซลล์ Sheet ซึ่งจำกัดประมาณ 50,000 ตัวอักษรต่อเซลล์ ลายเซ็นปกติมีขนาดเล็กพอ แต่ถ้ามีข้อมูลจำนวนมากควรเก็บลายเซ็นไว้ใน Google Drive แทน
- **การรีเฟรชข้อมูล:** หน้าเว็บดึงข้อมูลใหม่ทุก 15 วินาที ไม่ได้อัปเดตแบบทันที
- **โควตาของ Google Apps Script:** การใช้งานปกติของทีมขนาดเล็กถึงกลางเพียงพอ แต่มีโควตาการเรียกต่อวัน
- **วันที่และเวลา:** ใช้เวลาของเครื่องที่เปิดหน้าเว็บ ควรให้พนักงานตั้งเวลาเครื่องให้ถูกต้องและเป็นเขตเวลาประเทศไทย
- **ทดสอบ:** ยังไม่ได้ทดสอบ Apps Script กับ Sheet จริงและกับเครือข่ายของบริษัท ควรทดลองกับรายชื่อจำลองก่อนใช้งานจริง

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| หน้าเว็บขึ้นว่า "ยังไม่ได้ตั้งค่า API_URL" | ยังไม่ได้วาง Web app URL ในไฟล์ `index.html` |
| โหลดข้อมูลไม่สำเร็จ | ตรวจว่า Web app ตั้ง Who has access เป็น Anyone และ URL ถูกต้อง |

| วันที่ในชีตแสดงผิดรูปแบบ | ชีตถูกตั้งเป็นข้อความทั้งหมดตั้งแต่สร้าง ถ้าเกิดจากการแก้มือ ให้ตั้งคอลัมน์เป็น Plain text |
